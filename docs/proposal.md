# Masquera

_Collect, animate, and battle with NFT werewolf characters in a Web3 social deduction game_

## Summary

Masquera turns the classic werewolf game into a character-collection experience: players own animated NFT avatars with unique traits that unlock special in-game abilities (e.g., a Seer's reveal, a Witch's potion). An in-house anime designer creates distinct character art and animations, while the smart contract layer handles trait-based ability triggers and cosmetic marketplace trading.

## Target users

NFT collectors and anime fans who enjoy character-driven games and want collectible utility beyond static JPEGs

## Problem

Most Web3 games either ignore art/identity or treat NFTs as static speculative assets with no real gameplay utility.

## Solution

Give each NFT character functional, trait-driven special abilities inside werewolf matches, created by an anime artist to maximize emotional attachment and tradability.

## MVP features

- Mint animated NFT werewolf characters with randomized trait-based special roles/abilities
- On-chain ability resolution: trait metadata determines in-game power (e.g. double-vote, immunity)
- Marketplace for trading/renting character NFTs between matches
- Free starter characters for new players alongside premium animated collections
- Leaderboard NFT badges minted for top-performing characters each season

## Tech

## Why now

Metaplex's mature NFT tooling plus growing demand for utility-driven (not purely speculative) NFTs make this the right time to merge collectible art with functional gameplay.
